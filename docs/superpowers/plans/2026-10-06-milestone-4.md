# Milestone 4：Dual Deck + Mixer Core

使用者已明確授權此規格與執行；沿用已接受 Audius／Web Audio，不重新討論 provider，不執行最終手動驗收。依既有工作區執行；無 Git，不建立提交或 worktree。

## 設計

- 兩個相同 DeckEngine，獨立 snapshot、session、generation／stale-event 防護。
- 同一 WebAudioRuntime／AudioContext；保留既有獨立 createSession 以相容 M3 測試，新增具 Deck identity 的 routed session factory。
- Source → session-owned Deck Gain → mixer-owned Crossfade Gain A/B → Master Gain → destination。單一 session 不能 disconnect mixer 或 close context。
- MixerEngine 外置 React，以訂閱 snapshot 同步 UI；x∈[-1,1]，θ=(x+1)π/4，A=cosθ、B=sinθ；端點精確零。
- 共用 composition owner 在卸載應用時 dispose 兩 Deck、Mixer、runtime；runtime 也清理剩餘 sessions。
- 沿用 Deck／Mixer 視覺，接線 B、獨立 Unload、Crossfader／Master；Audius 結果可 Load A/B；YouTube 搜尋保留且不修播放。
- 不新增 EQ／其他後續功能；final checklist 全未勾選。

## Review focus

- Crossfade Gain 不與 Deck Gain 混用；不存在繞過 Master 到 destination 的連線。
- 換曲、dispose A、unload B 不關閉共享 context，不影響另一 Deck。
- runtime cleanup 可重入／pending load 會取消；React StrictMode 舊 owner 不影響新 owner。
- finite input／clamp／crossfade power sum 與兩端零。
- provider allowlist 與既有 YouTube 保護不改；mock 不等同實際聽感。
