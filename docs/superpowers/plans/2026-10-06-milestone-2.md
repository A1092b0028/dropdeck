# Milestone 2 Implementation Plan

> 使用 superpowers:executing-plans 在本工作區依序實作；完成後以獨立唯讀審查檢查範圍與契約。

**Goal:** Search UI 可透過 YouTube service 呼叫 Tauri，以 yt-dlp 搜尋並顯示正規化 Track[]。

**Architecture:** UI → 搜尋狀態 hook → TypeScript YouTubeService interface → Tauri command → Rust YouTube service → yt-dlp。Rust 端正規化並回傳可序列化的錯誤。所有 Deck/Mixer 保持現有停用占位介面。

**Tech Stack:** 現有 React/TypeScript/Tauri；新增 Tauri JavaScript API，以及 Rust serde、serde_json、tokio process/time。

**Spec:** ../../../spec.md 與使用者提供的 Milestone 2 需求；根目錄 AGENTS.md。

## Constraints

- 僅搜尋及 metadata，不下載、不解析串流、不播放、不建立音訊引擎。
- Load A/B 保持 disabled；不改 Deck/Mixer 實作。
- 10 筆結果；query 去除空白後需有內容，最多 200 字元。
- duration 為秒數或 null；channel 缺省顯示未知頻道；thumbnail 缺省使用影片 ID 的標準 YouTube 縮圖。
- 不透過 shell 字串組合指令；忽略外部 yt-dlp config；逾時中止子程序。
- Rust/Cargo 不存在時只記錄缺少工具，不能宣稱原生驗證通過。

## Review Focus

- 非法、空白或過長 query 不啟動 yt-dlp。
- 缺少 yt-dlp、執行錯誤、網路/搜尋失敗、無結果、無效 JSON 各自有明確處理。
- 未知/直播時長、超過一小時時長、Unicode 與長標題均正常顯示。
- UI 重送搜尋及錯誤後重試不顯示過期結果；browser preview 不偽造搜尋資料。
- Tauri command 命名、Track 欄位、錯誤碼與 thumbnail CSP 一致。
