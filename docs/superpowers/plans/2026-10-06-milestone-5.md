Signal: source -> low shelf -> mid peaking -> high shelf -> filter stage (fixed low-pass then high-pass) -> existing deck gain -> existing crossfade gain -> existing master -> output. The filter stage has two nodes controlled by one normalized value; no live node-type switching. Neutral LP=Nyquist, HP=0. LP endpoint 60 Hz; HP endpoint 12 kHz (sample-rate capped). Smooth changed gains/cutoffs over 30 ms with hold-and-ramp.

## Review focus
- Filter neutral must be unity without replacing node types while moving controls.
- Q units differ: mid peaking Q linear; LP/HP Q dB in Web Audio.
- Updates during pending resolution/replacement must apply latest state, not an old captured snapshot.
- Unload/replacement/disposal must disconnect all old DSP nodes, leave other deck/mixer/context running.
- Reset DSP must preserve volumes/crossfader/master and not modify other deck.
- No timers for smoothing; no graph rewiring during control changes.
