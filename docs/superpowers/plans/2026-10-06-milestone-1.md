# Milestone 1 Implementation Plan

> Execute inline with superpowers:executing-plans; keep this milestone limited to scaffolding.

**Goal:** Initialize YT-DJ with React, TypeScript, and Tauri and four static placeholder panels.

**Architecture:** React owns the shell and reusable deck view. Separate audio, services, stores, and types folders reserve the boundaries in spec.md. The Tauri host only opens the application window.

**Tech Stack:** React, TypeScript, Vite, Tauri 2, npm.

**Spec:** ../../../spec.md plus the user's explicit Milestone 1 scope and AGENTS.md instructions supplied in chat (no AGENTS.md file exists).

## Constraints

- No YouTube searches, playback, yt-dlp integration, or audio/mixer implementation.
- No state-management dependency or speculative engine/service interfaces.
- Use the same deck component for Deck A and Deck B.
- Keep the existing spec unchanged; this directory is not a Git repository.
- Use typechecking, production build, configuration checks, and a browser smoke check for this static scaffold; no core audio logic exists to test.

## Review Focus

- All four placeholders are visible and clearly inactive.
- Narrow layouts preserve panel content and accessible labels.
- The Vite development port matches Tauri's devUrl and uses strictPort.
- Tauri frontendDist resolves to Vite's production output.
- Native build limitations are reported without claiming desktop verification.
